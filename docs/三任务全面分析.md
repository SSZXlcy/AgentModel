## A　气体识别

### 公开数据

| 项 | 内容 |
|---|---|
| 来源 | 训练集 = UCI Gas batch1（445 条），验证集 = batch2（1,244 条），**逐字节一致** |
| 特征 | 16 个传感器 × 8 个特征 = 128 维 |
| 类别分布 | 训练集：乙醇 90 / 乙烯 98 / 氨 83 / 乙醛 30 / 丙酮 70 / 甲苯 74<br>验证集：164 / 334 / 100 / 109 / 532 / **5**，甲苯只有 5 条，Macro-F1 方差很大 |
| 排列方式 | 同一种气体连成一块排列，按顺序切出的每批只有两三种气体 |
| 漂移（batch2 相对 batch1） | 中位 0.54σ，p90 1.12σ，最大 11.46σ；128 个特征中 16 个超过 1σ |
| 标准化是否被冲坏 | 不会：clip 命中率最高 1.93%，中位 \|z\| 0.65–0.91 |
| 波动范围 δ | 0.053（Macro-F1） |
| 指标陷阱 | 官方 Macro-F1 在"真值 ∪ 预测"出现过的类别上平均：**某批没有甲苯时，误报一条甲苯就多出一个 F1=0 的类** |

公开数据流（验证集切成 4 批）结果：三种系统都是 0，无脑更新 −0.024。**数据流太短，测不出差别。**

### 隐藏流候选：batch3–10

| batch | 3 | 4 | 5 | 6 | 7 | 8 | 9 | 10 |
|---|---|---|---|---|---|---|---|---|
| 条数 | 1,586 | 161 | 197 | 2,300 | 3,613 | 294 | 470 | 3,600 |
| 甲苯 | 0 | 0 | 0 | 有 | 有 | | | 600（六类各 600，完全均衡） |
| 冻结模型 Macro-F1 | 0.594 | 0.489 | 0.627 | 0.323 | 0.327 | 0.266 | **0.185** | 0.381 |

（对比：batch1 上 0.956，batch2 上 0.714。按每批 300 条切成 41 批时，冻结模型平均 **0.366**。）

**实测（结构设计的依据）**
- 用第 k 批适应后，在第 k+1 批上 **8/8 次有帮助**，平均 +0.225，最高 +0.49；
- 在第 k 批自身上评估平均 0.90，在第 k+1 批上只有 0.62，**当批评估高估 0.28**；
- 用全部历史训练 5 次中赢 4 次；但数据量够了以后近期数据更好（例如预测 b8 时，只用最近两批 0.889，全部历史 0.791）。

**评估结果**

| 测试 | 不更新 | 无脑更新 | 只有训练层 | 完整系统（兜底） | 完整系统（27B） |
|---|---|---|---|---|---|
| 第 1 次（11-13，单系统） | 0.366 | | | **0.628**（换模型 22 次、回退 3 次、标注 6,110 条） | |
| 第 3 次（11-14，五方对照） | 0.366 | **0.678（+0.312）** | 0.615（+0.249） | 0.412（+0.046） | 0.539（+0.173），约 20 万 Token/次 |

第 2 次是策略层验证："稀有类加权 + 标签平滑" **+0.027，超出波动范围 0.025**，却因计时噪声被误判为"变慢"而拒绝；每批练 4 轮显著变差（−0.082）。

**结论**：A 是唯一一个"越积极越好"的任务。完整系统输给无脑更新，根因已定位：
1. 运行中验证的测量缺陷（已修）；
2. T6"有漂移但停滞"被错误地接到暂停更新（已修）；
3. 当批答案只拿一半训练，门槛又偏严（新的 `mode.adaptive` 针对这一点，**尚未验证**）。

## B　轴承剩余寿命

### 公开数据

| 项 | 内容 |
|---|---|
| 训练集 9 根，7,032 快照 | 1_1(123) 1_2(161) 1_3(158) 2_1(491) 2_2(161) 2_3(533) **3_1(2,538) 3_2(2,496)** 3_3(371) |
| 验证集 3 根，1,679 快照 | 1_4(122) 2_4(42) 3_4(1,515) |
| 三种工况 | 35Hz12kN / 37.5Hz11kN / 40Hz10kN；工况 1 寿命 120–160 分钟，工况 3 寿命 371–2,538 分钟 |
| 输入 | 水平、垂直各 17 个振动特征（强度、波形、冲击因子、频谱、三个频带能量） |
| 答案 | 第 i 个快照 = N − i（距最后一次采集的分钟数） |
| 目标缩放 | 均值 954，尺度 785（训练集拟合） |
| 设备失衡 | 最大组 / 中位组 = 6.8；两根长寿命轴承约占 70% 的数据 |

**实测**
- "官方基线练过头"是假象：epoch 1 的聚合 RMSE 是 580，epoch 15 是 681，但逐根看，1_4（453→242）和 2_4（462→391）都是**多练更好**，只有占 90% 样本的 3_4 变差（592→711）。
- 按轴承分组算的波动范围是 **±375 分钟**；不分组时低估 21 倍。
- 官方模型在训练集上的逐根 RMSE：1_1 119、**1_3 483**、**2_2 404**、3_3 222、3_1 253、3_2 210，**短寿命轴承普遍被说长**。
- 只看一个快照判断工况，准确率 40.6%（随机猜 33%），**基本分辨不出工况**。
- 12 根轴承轮流留一、每根最多取 300 条：平均 RMSE 670 → **550（−18%）**；9 根短寿命轴承 513 → 346（−33%），3 根长寿命 1,141 → 1,163（+2%），12 根中 8 根变好，训练数据量减少约 60%。

**公开数据流（验证集切成 8 批，每批 200 条）**

| 答案时机 | 无脑更新 | 只有训练层 | 兜底 | 27B |
|---|---|---|---|---|
| 当批给（**不现实**，早期 +69.5 已更正为虚高） | +56.7 | +72.1 | +68.7（训练量只有训练层的 35%） | +66.6 |
| **设备跑完才给（现实）** | **−17.0，显著变差** | 0 | **+17.3，显著变好** | +7.3 |

现实协议下每批拿到的答案：第 0 批 86 条，第 1–6 批 **0 条**，第 7 批一次性补发 754 条。兜底版的提升全部来自开局：在 9 根训练轴承上按组 k 折验证"每台上限 371 条"，+185（波动 132）。修改说明书之后的新版本单种子冒烟：**+19.9**。

**被比赛协议卡住的改进**（潜力最大）：预测请求只能带当前快照的 34 个特征，**没有轴承编号、历史快照和工况**，所以无法利用趋势，也无法用"每分钟减 1"做前后校正。

## C　涡扇发动机剩余寿命

### 公开数据

| 项 | 内容 |
|---|---|
| 训练集 113,089 行 | FD001–004 的发动机 1–70 / 1–182 / 1–70 / 1–174（系统的初始训练配方固定抽 2 万行子集） |
| 验证集 23,049 行，106 台 | 71–85 / 183–221 / 71–85 / 175–211 |
| 输入 | 3 个工况设置 + 21 个传感器，`window_size = 1`，**单周期，没有滑窗** |
| 答案 | 不封顶，最大 542 |
| 设备失衡 | 2.6（不到 3，不触发均衡） |

**为什么没有漂移**：四个子集混合后按发动机编号切分，训练集已覆盖全部工况和故障类型。
- 子集内训练集与验证集的 MMD 只有 0.001–0.038，子集之间达 0.76–0.85；
- 训练集 RMSE 55.4，验证集 52.9，新发动机上并没有变差。

**误差从哪来**

| 来源 | 证据 |
|---|---|
| 工况掩盖退化信号 | FD002/FD004 的传感器方差几乎 100% 来自 6 种工况；读数与剩余寿命的相关度在原始读数上只有 0.05，按工况校正后升到 0.63 |
| 单周期信息不够 | 真实剩余寿命 50–100 周期时，平均**说长 35 个周期**（RMSE 47.6）；200 以上时**说短 81 个周期**（RMSE 99.5） |
| 两种故障模式 | 各子集 RMSE：FD003 64、FD004 62；FD001 44、FD002 46 |

公开数据流（11 批）：三种系统都是 0，无脑更新 +0.44（不显著），27B 每次运行约 9.1 万 Token 却没有改进。策略层验证中，"高估加重惩罚 + 目标区间均衡"让 RMSE 变差 2.28（如果平台也看 NASA 分数，这个结论可能不同）。

所有差别都在波动范围内，和"C 没有可利用的漂移"一致。测试文件是中途截断的发动机，剩余寿命分布和训练数据不同，冻结模型 RMSE（约 43.8）也比验证集（52.9）低，**这一点尚未细查**。

**结论**：C 的最好策略是不更新、少花钱；真正的提升要靠改输入（工况校正、历史窗口），但受预测协议限制。

## 跨任务结论

1. **三类任务对应三种节奏**，由"答案及时程度"和"漂移是否可利用"自动区分。这就是策略层存在的理由。
2. **提升都来自"在已知答案的数据上验证过的修正"**：A 来自下一批的确认，B 来自历史设备上的留一验证。
3. **27B 在三个任务上都没有胜过规则**，但每次都正确识别了数据结构，还发现过系统缺陷。
4. **B 和 C 的天花板在输入协议**，需要赛题组确认：能否提供历史窗口或工况；客观分是否看 NASA 分数。
